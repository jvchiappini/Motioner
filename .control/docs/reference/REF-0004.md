# MDF v0 language specification

## Overview

MDF (Motioner Document Format) is the program-first, Python-like
language that builds a composition. This reference summarizes the
decisions and points to the full specification with grammar and
examples.

Full specification: `spec/mdf-v0.md` at the repository root.

## Confirmed semantics

- Program-first: the MDF program is the canonical source (D-0011).
- Custom deterministic DSL, not embedded Python.
- Python-like syntax: indentation, functions, conditionals, loops,
  expressions, collections and calls.
- Sandboxed execution: no filesystem, network, process or ambient time.
- Running a program produces a document snapshot with provenance.
- UI edits become overrides keyed by stable identity, or bake elements.
- LaTeX math typesetting is part of the 1.0 language (D-0016).
- The same language is used on disk, in the code panel and by the AI.

## Non-goals for v0

- Importing Python packages.
- Arbitrary macros or full LaTeX documents.
- Dynamic code generation outside the sandbox.
- A general-purpose language beyond scene construction.

## Deferred to v0.1

- `use`/module semantics for shared helpers.
- Override sidecar, bake and orphan reporting.
- Error recovery and formatting rules.
- Resource-limit defaults.
- LaTeX command subset.

## Status

Frozen v0 subset on 2026-10-31. The first implementation covers the
subset listed in the specification; `while`, `use`, overrides and LaTeX
are deferred to v0.1 and do not block the first MP4.
