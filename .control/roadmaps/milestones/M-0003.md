# Milestone: Ten-second 2D composition animates headlessly

## Description

A 10-second composition with nested groups and keyframed transforms
evaluates correctly at every frame and renders a frame sequence without
a UI. This validates the timeline, the evaluator and the render plan.

## Verification criteria

- [ ] Every frame evaluates without errors.
- [ ] Animation curves produce the expected values at sampled frames.
- [ ] The render plan is identical for preview and export paths.
- [ ] Evaluation is allocation-free per frame in benchmarks.
