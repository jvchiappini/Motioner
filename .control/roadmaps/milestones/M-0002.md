# Milestone: First deterministic frame from a project file

## Description

A fixture project loads, evaluates a single fixed frame and renders it
offscreen through the engine twice with identical output. This proves
the format, the engine host and the determinism contract together.

## Verification criteria

- [ ] The project file loads and validates.
- [ ] The frame renders offscreen without an open window.
- [ ] Two runs produce the same hash or a diff within tolerance.
- [ ] The golden frame is committed to the test kit.
