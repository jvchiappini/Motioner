# Milestone: 3D layer composited over 2D with effects

## Description

A 3D scene with a model, camera and light composites over 2D layers in
the same composition, with at least one GPU effect and color-managed
output.

## Verification criteria

- [ ] Depth and alpha composite correctly with 2D layers.
- [ ] At least five effects run in preview and export.
- [ ] Color management produces consistent references.
- [ ] VRAM stays within the budget at 4K.
