# Milestone: AI creates a composition from a prompt

## Description

From a natural-language prompt, the agent builds a multi-layer animated
composition using typed tools. The result is previewable, undoable and
expressed as readable code.

## Verification criteria

- [ ] A prompt produces a valid composition with at least three layers.
- [ ] Every change is a reviewable, undoable transaction.
- [ ] The composition round-trips document -> code -> document.
- [ ] The agent cannot perform I/O or shell execution.
