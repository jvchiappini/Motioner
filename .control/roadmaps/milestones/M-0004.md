# Milestone: Interactive editor preview at target fps

## Description

The editor displays a live viewport fed by the renderer, with working
selection, timeline scrubbing and playback that stays responsive at
proxy quality.

## Verification criteria

- [ ] Playback reaches the target fps at proxy resolution.
- [ ] Scrubbing and selection do not block the UI.
- [ ] Edits update the viewport within one frame budget.
- [ ] Layout and selection survive an editor restart.
