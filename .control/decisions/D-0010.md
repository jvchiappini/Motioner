## Contexto

The original five-phase plan covered 2D, 3D and AI, but the user
confirmed a much broader product: NLE video/audio editing, a full audio
mixer, a node graph, advanced 3D, automatic AI iteration and public
distribution. A solo developer cannot ship all of it at once without a
defined 1.0.

## Decision

Approved by the user on 2026-10-31.

1.0 is Windows-only and 1080p-first:

- 2D motion graphics: shapes, text, images, video, audio.
- AE-style timeline, keyframes and curves, masks, mattes, precomps,
  adjustment layers and effects.
- Basic node graph as an alternate view of the same document.
- NLE: cut, trim, arrange, transitions and sync.
- Audio: stereo mixer with volume, pan, fades and a basic effects chain;
  no advanced mastering.
- 3D: glTF, cameras, lights, PBR, skeletal animation and GPU particles.
- Python-like MDF code with executable loops, conditionals and functions.
- AI chat, preview rendering, visual critique and automatic iteration,
  with human approval for the final render.
- MP4 and PNG export at up to 1080p; manual upload to YouTube.
- CPU tests in CI and manual GPU golden frames.

Post-1.0: 1440p/4K, rigid-body physics, cloth and fluids, color grading,
advanced audio mastering, HDR, macOS/Linux, plugin API, collaboration,
cloud rendering.

## Consecuencias

Gains:
- A coherent, demoable 1.0 with the product's core promise.
- Clear exclusions prevent scope creep and unverifiable claims.
- The north star remains full parity and maximum capability.

Costs:
- Some highly desired features ship after 1.0.
- NLE and audio still add substantial work to 1.0.
- 1080p-first means 4K workflows wait.

Pending:
- Fine-grained feature matrix per initiative.
- Whether rigid-body physics can move into 1.0 if schedule allows.
