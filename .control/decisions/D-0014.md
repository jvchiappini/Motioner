## Contexto

The reference machine is a laptop with 8 GB of RAM and a 6 GB RTX 4050.
Full NLE, 3D, audio and AI work at 4K would exceed its memory and VRAM
budgets. The user approved prioritizing 1080p and lowering the 4K target.

## Decision

Approved by the user on 2026-10-31.

- Windows is the first platform and the reference platform.
- 1080p is the primary authoring, preview and export target.
- Preview targets 60 fps at full quality on the reference machine.
- Quality may drop only while scrubbing; playback and export use full
  quality.
- 1440p and 4K, HDR and wide gamut are post-1.0.
- The application must explicitly select the high-performance NVIDIA
  adapter.
- Memory and VRAM budgets are mandatory; caches and proxies are bounded.

## Consecuencias

Gains:
- A realistic performance target for the actual hardware.
- A clear quality policy for preview, scrubbing and export.
- Budgets that prevent out-of-memory failures.

Costs:
- 4K workflows wait.
- 8 GB of RAM still limits timelines, frame caches and AI previews.
- Hybrid graphics requires explicit adapter handling.

Pending:
- Numeric budgets per subsystem.
- Whether the user upgrades RAM; if not, 1.0 stays 1080p.
- Cross-machine determinism tolerance policy.
