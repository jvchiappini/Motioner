## Contexto

Motioner is described as a code-driven video generator with an
After Effects-like editor and an AI chat. Three authoring surfaces need
to agree: direct manipulation, text code and agent instructions. Two
possible truths exist: a structured document that the UI edits, or a
text program that generates everything.

## Decision

Confirmed by the user on 2026-10-31.

The structured document is the single source of truth. The motion
language is a complete, lossless projection of that document:

- Document to code is deterministic, with stable ordering and
  idempotent formatting.
- Code to document compiles into document commands.
- Round-trip tests assert semantic equality in both directions.
- AI edits use the same typed commands as the UI; when the AI writes
  code, the code is compiled into those commands.
- The document is never generated implicitly from code at runtime.

## Consecuencias

Gains:
- One truth: no merge conflicts between a file and an in-memory model.
- Full undo and audit for UI, code and AI edits.
- The UI can edit anything the language can express, and vice versa.
- The project format remains structured and migratable.

Costs:
- The language must stay in sync with the document schema; a schema
  change is a language change.
- Human formatting and comments may not survive a round-trip unless
  explicitly modeled; this limitation must be documented.
- The code panel cannot be a free-form program that owns state.
