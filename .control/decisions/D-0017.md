## Contexto

Several 1.0 details were still open. The user confirmed a set of
defaults on 2026-10-31 to remove ambiguity before implementation.

## Decision

Approved by the user on 2026-10-31.

- AI iteration budget: 10 iterations, 10 minutes and a configurable cost
  cap per task.
- Final render and any expensive operation require human approval; the
  AI never uploads.
- Audio 1.0 effects: EQ, compressor and limiter, plus volume, pan and
  fades. No reverb or delay in 1.0.
- Node graph in 1.0 is basic compositing, not a full advanced node set.
- GPU particles are in 1.0. Rigid-body physics is post-1.0; cloth and
  fluids come later.
- UI language in 1.0 is English only; Spanish is a later localization.
- Windows packaging: MSI or NSIS installer plus a portable ZIP. No
  auto-update in 1.0.
- Export target is 1080p; 1440p and 4K are post-1.0.
- Video publishing is manual: the user downloads the MP4 and uploads it.
- CI has no GPU; rendering is verified with a CPU oracle and manual GPU
  golden frames on the reference machine.

## Consecuencias

Gains:
- No ambiguity in 1.0 behavior.
- Predictable cost and safety for automatic iteration.
- A realistic packaging and quality target.

Costs:
- Some effects and platforms wait.
- Manual GPU verification is a recurring process cost.
- Localization is delayed.

Pending:
- Exact audio effect parameter ranges.
- Cost cap defaults and provider pricing display.
- Installer technology choice between MSI and NSIS.
