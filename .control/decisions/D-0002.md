## Contexto

Motioner promises professional output and an interactive preview. If the
preview and the exported video are produced by different code paths, or
if time accumulates as floating point, the two will drift. Users will
see one result and export another.

## Decision

Evaluate frames deterministically from a document revision.

- Time is an integer frame number plus a rational fps, never accumulated
  wall-clock deltas.
- Evaluation is a pure function of document version, frame, fps, render
  settings and asset snapshot.
- Preview and export call the same evaluator; only resolution, sample
  counts and quality settings differ.
- Randomness is seeded from stable inputs; no ambient RNG, no wall clock,
  no I/O during evaluation.
- Golden-frame tests and documented numeric tolerance verify the
  contract across runs and machines.

## Consecuencias

Gains:
- Preview and export agree by construction.
- Reproducible renders, testable animation and reliable caches.
- Simpler reasoning about undo, snapshots and background jobs.

Costs:
- Every feature must be expressible as a function of frame state.
- GPU floating-point differences across vendors require tolerance
  policies and reference hardware.
- Some effects must give up unseeded noise or time-based shortcuts.

Pending:
- Define the tolerance policy per effect and per platform.
- Define how interactive playback behaves when frames are skipped
  without changing frame results.
