## Contexto

Procedural motion and AI-generated logic need more than static keyframes.
Allowing arbitrary native code or unrestricted scripts would break
determinism, security, reproducibility and cross-platform rendering.

## Decision

Provide a sandboxed, deterministic script runtime for expressions and
generators.

- Scripts receive explicit inputs: frame, fps, composition context,
  seeded RNG and property values.
- No filesystem, network, process or ambient time access.
- Fuel, instruction and time limits; execution is interruptible.
- Outputs are typed and validated before they reach the document.
- The same script and inputs produce the same result on every platform.
- Script sources are stored in the project and versioned like code.

The concrete engine (custom interpreter, Rhai, or another embeddable
Rust runtime) is chosen by a spike; determinism and sandboxing are
non-negotiable requirements.

## Consecuencias

Gains:
- Safe AI-generated motion logic.
- Reproducible procedural animation.
- Bounded resource usage.

Costs:
- A new language surface to document, test and fuzz.
- Some users will want unrestricted scripting; that is a separate,
  higher-risk feature.
- Performance overhead compared with native expressions.

Pending:
- Pick the runtime and measure per-frame cost.
- Define the exposed API surface and limits.
- Decide how errors are surfaced in the UI and to the AI.
