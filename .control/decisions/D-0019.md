## Contexto

The first Motioner render (T-RENDER-0002) needs two things the pinned
engine commit `02e6d4873379e3f7b92406bd5c63d0ad1c80bdee` did not offer:
text drawn by the Pure2D renderer with real font metrics, and a frame
readback that reuses its buffers and returns typed errors instead of
panicking. Building either inside `motioner_render` would duplicate engine
code, so both were added upstream first (T-RENDER-0003).

## Decision

Pin `engine/ferrous` to `32aea8af74a510c1d89456e861b6dd8dbaeb167f`
(2026-10-31), the head of FerrousEngine branch
`feat/pure2d-text-and-readback`. The submodule model of D-0018, its
sparse patterns and its dependency boundaries are unchanged.

The commit adds:
- `ferrous_font`: hhea/head metrics, kerning, glyph bounds, typed
  `FontError` and the pure-CPU `layout_line`.
- `ferrous_2d`: MSDF text instances drawn in z order with shapes and
  sprites.
- `ferrous_renderer`: `register_font_2d`, `draw_text_2d`,
  `measure_text_2d`, `read_rgba8_into`, `ReadbackError`, `HarnessError`,
  configurable clear colour, and a headless path that builds without the
  `gui` feature.

Checks on the new pin, from the Motioner root with `CARGO_INCREMENTAL=0`:
`cargo build --workspace`, `cargo clippy --workspace --all-targets -- -D
warnings` and `cargo test --workspace` (91 passed) are green, and
`scripts/check_boundaries.py` reports OK.

## Alternativas consideradas

- Interim CPU text rasterisation inside `motioner_render`: rejected
  because it duplicates font code that belongs in the engine and would be
  thrown away.
- Waiting for the branch to merge into FerrousEngine `main`: rejected for
  now; the pin is a commit, so it stays reproducible, and the merge can
  follow the polish pass.

## Consecuencias

Gains:
- Motioner can render text and read frames back through engine APIs only.
- Readback failures surface as typed errors that `motioner_render` maps
  into its own error type.

Costs:
- The pin is on a feature branch, not on engine `main`.

Pending (engine polish pass, later pin bump):
- The two-slot readback does not overlap work yet: `render_frame` and
  `take_readback` both block on `Maintain::Wait`, and mapping starts only
  at take time. A failed map also leaves its slot pending.
- The hard-edge tolerance band in `assets/shaders/shape_2d.wgsl` can
  reject a pixel the rasteriser assigned, within 1e-3 px of a shared
  internal triangle edge.
- Freed `FontId2d` values are recycled without a generation, so a stale
  id can draw with a different font.
