## Resumen

A keyed content property (fill, stroke, stroke_width, width, height, radius,
trim/dash, text size/colour) travels from the document through sampling into
the render plan and the painted frame, and the editor exposes the same path
as channels, timeline rows and JSON. A path item additionally carries its
geometry through the plan's arena and is tessellated and cached in the
renderer (D-0029). A gradient fill/stroke resolves its stops into the same
arena and the renderer uploads one per-frame table (D-0030). A non-normal
blend mode, or a node with an effect chain, renders the node's subtree into an
engine layer before compositing (D-0031, D-0032).

## Pasos

1. The DSL writes a key: `Scene::key_content` converts the MDF value and calls
   `Document::add_content_keyframe` - `crates/motioner_dsl/src/scene.rs:428-500`.
2. The core validates the field, value, frame and kind and inserts the key in
   the matching `Animatable` channel -
   `crates/motioner_core/src/document.rs:301-360`,
   `crates/motioner_core/src/node.rs:492-565`.
3. The editor stores the same edit as an `override_key` statement; applying the
   set calls the same core write -
   `crates/motioner_core/src/overrides.rs:280-320`.
4. The evaluator samples the channels at the frame; colours interpolate in
   linear light and an optional colour with a `none` endpoint holds -
   `crates/motioner_eval/src/evaluate.rs:102-150`,
   `crates/motioner_eval/src/curve.rs:58-125`. Every gradient stop is sampled
   (offset clamped, sorted) into a `ResolvedGradient` in the plan arena and
   `ResolvedPaint` keeps a solid colour or a gradient index (D-0030) -
   `crates/motioner_eval/src/evaluate.rs:155-225`,
   `crates/motioner_eval/src/plan.rs:14-52`.
5. The plan carries resolved geometry, paint, trim and dash (no `Animatable`
   escapes `motioner_eval`) plus the node's blend mode. Path geometry lives in
   the plan's arena and the item holds an index -
   `crates/motioner_eval/src/plan.rs:7-140`,
   `crates/motioner_eval/src/evaluate.rs:145-190`.
6. The renderer paints the resolved values (headless and live share
   `paint_plan`). Paths are cut, tessellated and cached per node before the
   triangles are submitted. The gradient table is built once per frame and
   uploaded into the 2D camera uniform; shape and text instances reference an
   entry (D-0030) - `crates/motioner_render/src/frame.rs:90-130`,
   `crates/motioner_render/src/shapes.rs:52-205`,
   `crates/motioner_render/src/paths.rs:30-320`,
   `crates/motioner_render/src/gradients.rs:1-219`.
7. The evaluator wraps a node with a non-normal blend mode or an effect chain
   in a `PlanLayer` covering its whole drawn subtree, and samples the effect
   chain into it (D-0032). The renderer opens one engine layer per range at
   the first item's depth and closes it after the last item, so a group's
   blend and effects apply to the subtree and nested layers nest -
   `crates/motioner_eval/src/evaluate.rs:60-200`,
   `crates/motioner_render/src/frame.rs:120-235`,
   `crates/motioner_render/src/lib.rs:88-140`. All seven blend modes composite
   through `CompositeMode2d` on the pin (D-0031); the backdrop-aware modes
   copy the destination into a scratch texture first.
8. Effect passes (blur, drop shadow, glow) are engine work still missing from
   the pin, so `render` returns `RenderError::Unsupported { feature: Effect,
   node }` before painting; the document, plan and editor are complete and the
   golden still is committed (D-0032) -
   `crates/motioner_render/src/frame.rs:70-82`,
   `crates/motioner_render/src/lib.rs:243-260`.
9. The editor reads the same channels for the inspector, the timeline rows
   (stopwatch, diamonds, eased lines) and `query`. The blend mode is a
   whole-node grid at the top of the inspector, not a channel; effect
   parameters are rows under an Effects section with add/reorder/remove
   tiles - `crates/motioner_ui/src/editor/channels.rs:60-300`,
   `crates/motioner_ui/src/timeline_model.rs:175-230`,
   `crates/motioner_ui/src/editor/query.rs:110-170`,
   `crates/motioner_ui/src/inspect.rs:850-990`.

## Dominios relacionados

- motioner_dsl (writes the key)
- motioner_core (stores it)
- motioner_eval (samples it)
- motioner_render (paints it)
- motioner_ui (edits and reports it)

## Notas de mantenimiento

Review when a new animatable value type is added (gradients, effects, masks,
paths) or when the render plan's content contract changes.
