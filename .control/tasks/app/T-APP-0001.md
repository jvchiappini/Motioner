## Contexto

An LLM must be able to do everything a person can do in the editor without
mouse coordinates or focus (AI-first). Design and decision: D-0024.

## Criterios de aceptacion
- [x] One `Command` enum (45 kinds, text names, MDF call syntax) executed by
      the window-free `Editor`; the window maps every gesture to it;
      `input::Action`/`Effect` deleted.
- [x] `motioner query` (JSON scene), `motioner edit` (all or nothing,
      `--dry-run`), `bake` and `info --json` through the same code.
- [x] `preview --control` endpoint (127.0.0.1, random token, endpoint file)
      polled without blocking; `motioner ctl` with `state()`, `query()`,
      `screenshot(path)`.
- [x] Parity tests: every kind round-trips and reaches the executor from the
      CLI and `ctl`; the prompt 08 run through `motioner edit` equals the
      `edit::apply` result; live `ctl` test with screenshot and undo.
- [x] `docs/agents.md`, README section; `scripts/ui_drive.ps1` replaced by
      `ui_shot.ps1 -Commands`.
