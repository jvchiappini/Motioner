## Contexto

`motioner_analysis` (D-0049) implements the design analysis of prompt 13 phase 7: exact frame description, hit testing, channel sampling, frame to code mapping, motion/layout/legibility reports, the `check_design` rule table and its documentation.

## Criterios de aceptacion
- [x] Crate created engine-free and file-system-free, with text measurement injected.
- [x] `describe_frame`, `hit_test`, `sample`, `code_for_node`/`node_for_code`.
- [x] `motion_report` (onsets, durations, peak speed, velocity jumps, eases, stagger, dead time, overload).
- [x] `layout_report` (overlaps, safe area, alignment groups, type hierarchy).
- [x] `legibility_report` (reading time and contrast against a render without the text).
- [x] `check_design` with one rule table in `rules.rs` and 14 documented rules.
- [x] `docs/design-rules.md` and 14 bad/good fixture pairs under `examples/design_defects/`.
- [x] Every preset and component passes `check_design` on three themes (tests) and all ten in release.

## Notas del agente

The contrast sampler is a trait implemented by `motioner_tools`/`motioner_app` over `motioner_render::tools::TextlessFrame`, so the analysis crate never names the renderer.
