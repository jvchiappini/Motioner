## Contexto

Phase 3 turns imported media into a panel: a Layers/Assets tab with a
virtualised list or grid, import by menu/panel/drop, non-PNG conversion,
fonts in the Family cycle, drag-to-place and unused-asset cleanup.

## Criterios de aceptacion
- [x] The left panel has Layers and Assets tabs; assets show a key, kind,
      size/duration and "used by N" (list) or a kind/waveform strip (grid).
- [x] Rows are virtualised and the panel adds **0 allocations/frame** with
      `alloc-count` (`out/ui/p11-05-alloc.png`).
- [x] Import hashes the bytes, copies to `assets/<sha256>.<ext>`, dedupes,
      records the entry and writes `project.motion`.
- [x] Non-PNG images are converted once through ffmpeg into `cache/<hash>.png`.
- [x] Imported fonts join the Family cycle; audio peaks are cached.
- [x] Double click and panel drag place an image layer at the drop point.
- [x] `remove_unused_assets` deletes unreferenced blobs after the CLEAN action.
- [x] `import_asset`, `remove_asset`, `rename_asset`, `place_asset` and
      `remove_unused_assets` have text parity and docs.
- [x] The gate is green.
