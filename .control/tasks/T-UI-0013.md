## Contexto

The prompt 11 review of phases 4.5-5 (a01fdc8, 5af994e) found five
issues: audio layers showed visual-only inspector/timeline rows; stray
"Y" glyphs fell back from the solo/shy/filter controls; the asset detail
column and effect buttons truncated at the minimum panel width; and the
timeline waveform read as flat blocks.

## Criterios de aceptacion
- [x] One kind -> property-set table: audio has no transform/blend/effect/mask
      and shows Source/Start/In/Out/Gain/Pan/fades/Mute/Solo.
- [x] Expanded audio timeline rows are Gain, Pan, Fade in and Fade out.
- [x] Commands that do not apply to the kind return a typed error with a
      parity test.
- [x] Every icon id has a glyph; mute/solo/filter/shadow/blur/glow are drawn.
- [x] At minimum panel widths the asset name and the effect buttons do not
      truncate; the detail becomes `×N` with a tooltip.
- [x] The waveform is a mirrored min/max adapter over the cached mip chain,
      clipped to the trim, with silence drawn empty.
- [x] Regression tests fail without each fix; screenshots re-taken.

## Notas del agente

`properties.rs` owns the table. `inspect_node` gained `MediaState`;
`timeline_model` gates transform rows. `channels::resolve` and
`resolve_edit` reject visual properties/effects/masks on audio.
`icons::Icon::ALL` + `has_glyph` cover the text-fallback guard.
`asset summary` carries a peak mip chain and video thumbnails.
