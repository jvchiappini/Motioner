## Contexto

Phase 2 makes Motioner open like an application: a start screen with recent
projects and examples, a New project dialog, a File menu, the window title and
typed commands for the project lifecycle (D-0045).

## Criterios de aceptacion
- [x] `motioner` with no arguments opens the start screen with New project,
      Open project, recent projects (name, path/detail, missing state and
      "remove") and the shipped examples.
- [x] New project collects name, location (native folder picker), size, fps,
      frames and background, creates the folder through Phase 1 and opens it.
- [x] Open accepts a folder, `project.motion` or a loose `.motion`; a missing
      recent entry is greyed with "remove".
- [x] A File menu offers New, Open, Save, Save a copy, Import asset, Reveal and
      Close project; the title is `<project> — Motioner` with a dirty dot.
- [x] `motioner <path>` still opens directly.
- [x] New commands (`new_project`, `open_project`, `close_project`, `save`,
      `save_as`) have text parity and a `docs/agents.md` entry.
- [x] The gate is green with `CARGO_INCREMENTAL=0` and `-j 2`.

## Notas del agente

- `motioner_ui::start`: pure start-screen state, layout, painting and actions.
- `motioner_ui::ProjectHost`: the io boundary trait, implemented by
  `motioner_app::host::Host` over `motioner_io` and `rfd` (D-0046).
- `app/project.rs`: open/close/create/save-as, start-screen input, File menu.
- `Editor::blank` and `Editor::replace_session` support switching projects.
- Screenshot: `out/ui/p11-01-start.png`.
- Thumbnails are generated later: drawing a bitmap in chrome needs an engine
  GUI image primitive, tracked as T-UI-0011.
