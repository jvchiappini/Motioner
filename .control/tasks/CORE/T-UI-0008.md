## Contexto

Prompt 10, Phase 10 (and Part A). Large scenes had flat "Circle 1..300" rows,
no collapse/filter/solo/shy, no value graph, and every frame laid out and drew
every outline/timeline row. Phase 9's live preview also showed motion blur as
an indicator only.

## Criterios de aceptacion
- [x] `node.name` display names, binding-derived defaults, overrides, `query`
      and `bake`.
- [x] Collapsible groups, `filter_layers`, `solo`/`shy`/`show_shy` (preview
      only).
- [x] Editable bezier fields in the inspector and a graph editor with key and
      handle drags as commands.
- [x] Live motion-blur preview through the shared accumulation pass (full
      samples paused, 4 while playing).
- [x] 1000-layer stress scene, virtualised rows, cached visibility runs and a
      per-frame allocation counter.
- [x] Screenshots `out/ui/p10-01..p10-10-*` and `out/stress_1000.motion`.
- [x] Gate green; `hello_f120.png` byte-identical.

## Notas del agente

D-0044 records the editor-state and performance decisions. The 1000-layer
preview measured 62 fps idle and 60 fps playing on the reference machine;
motion-blur preview playback also held 60 fps with the 4-sample cap. Residual
per-frame allocations in the status counter (48/frame on the stress scene)
come from formatting timeline values, not from the virtualised layout.
