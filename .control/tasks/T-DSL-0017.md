## Contexto

D-0039 section 4. Tempo comes from `comp(tempo=...)` or the theme;
`beat(n)`/`bar(n)` return seconds. `scene(name, start, length)` returns a
group with hold keys over its window and `scene.t(x)` converts scene-local
time to absolute time.

## Criterios de aceptacion
- [x] `comp(tempo=...)` and theme tempo feed `beat`/`bar`; every time argument still accepts seconds
- [x] `scene` groups are visible only inside their window and expose `t(x)`
- [x] scenes are named groups, so the outline shows them and the timeline shows their keys

## Notas del agente

Visibility compiles to opacity hold keys because the document has no keyed
visibility channel; this keeps scenes as ordinary nodes. Dedicated labelled
timeline ranges remain for T-DSL-0024.
