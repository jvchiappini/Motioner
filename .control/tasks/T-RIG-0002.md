## Criterios de aceptacion
- [x] use(path) returns a definition: a symbol (SVG), a module namespace (.motion), or an asset (image/audio/video/font). Definitions are callable and expose metadata (kind/path/width/height/parts).
- [x] Assets do not need a resolver: their path is resolved by the reader later; only SVG and .motion need the host resolver. image()/audio()/video() stay as sugar and are unchanged.
- [x] Sandbox: absolute paths and parent escapes outside the root are rejected before I/O; module cycles and missing imports are typed diagnostics at the use() span.
- [x] Modules execute once in the shared global scope and return a namespace of their top-level names (documented v0 import semantics in D-0051).
- [x] ProjectAssets in motioner_io implements the resolver; the CLI render/info/still paths use run_with_assets.
