## Contexto

D-0039 needs an implicit prelude so the shortest program is a good one. The
prelude is `crates/motioner_dsl/std/*.motion`, embedded with `include_str!`
and parsed before the user program (`crates/motioner_dsl/src/prelude.rs`).

read-only.
