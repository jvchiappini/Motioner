Phase work delivered in prompt 16 (session S-2026-11-11-001). See the notes for the concrete artefacts.

## Criterios de aceptacion
- [x] r.driver(fn) compiles a pure expression function into motioner_rig::Expr: numbers, property reads, + - * /, comparisons, and/or/not, min/max/abs/sin/cos/clamp/lerp.
- [x] Drivers return a list of [part, field, value]; fields are position.x/y, rotation, scale.x/y, opacity and stroke_width. Unsupported constructs are typed errors naming the driver.
- [x] Bake-on-build: the rig is evaluated for every composition frame and written as ordinary keys with hold-before-change frames, so the existing evaluator renders, scrubs and exports it with no changes.
- [x] Bounds: 64 writes per driver, 4096 per frame, 200k baked frames; non-finite values are typed errors.
- [x] Tests cover drivers, non-finite output, determinism and backwards seeking.
