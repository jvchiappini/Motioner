## Contexto

D-0039 section 3: composition-relative layout measured with the renderer's
own `TextMetrics` (D-0035). `place` and `bounds` are node methods; `row`,
`column`, `grid` and `stack` are scene builtins in
`crates/motioner_dsl/src/scene.rs`.

## Criterios de aceptacion
- [x] `node.place(anchor, x, y, margin)` with anchors, corners, fractions and text safe-area default
- [x] `row`, `column`, `grid`, `stack` measure text with the injected provider and accept gap tokens
- [x] `node.bounds()` returns the measured composition-space box, including group unions
