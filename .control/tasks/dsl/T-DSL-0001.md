## Contexto

`spec/mdf-v0.md` is the first draft of the program-first Python-like
language. D-0011 fixes the semantics (custom DSL, deterministic,
sandboxed) and D-0016 adds LaTeX. The job now is to review the draft,
resolve the open questions and freeze an implementable v0.

Focus on: module (`use`) semantics, override syntax, function and scope
rules, keyframe API, LaTeX subset, limits, and error model. The
specification must be precise enough that two independent
implementations would agree.

## Criterios de aceptacion
- [x] Every open question in section 17 is resolved or explicitly
      deferred.
- [x] Grammar and scene API are complete for the frozen v0 subset.
- [x] At least three example programs cover loops and functions.
- [x] The project links the frozen spec from REF-0004 and the README.

## Notas del agente

Frozen on 2026-10-31 by user approval. The v0 subset covers numbers,
strings, booleans, lists, variables, functions, conditionals, `for`,
arithmetic, comparisons, calls, attribute access, the 2D scene API,
keyframes and linear/eased interpolation. `while`, `use`, overrides and
LaTeX are deferred to v0.1 and do not block the first MP4.
