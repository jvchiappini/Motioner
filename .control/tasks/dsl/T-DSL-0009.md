## Contexto

Prompt 12 phase 3 (D-0036 section 2.2). A node created inside a `for` body is
fed by the same literal or expression on every iteration, so the planner must
write a guarded statement inside the loop body instead of editing the shared
literal or falling back to an override.

## Criterios de aceptacion
- [x] Guard built from the loop stack (`if i == 3:`, nested with `and`).
- [x] Inserted in the innermost loop body, after the node's last write, with
      the file's indentation and line endings.
- [x] Existing guard extended; repeated values merge into `if i in (1, 3):`
      (sorted); dead guards removed (this and all scopes); when the last
      iteration edit makes every instance equal, the shared literal is edited
      and all sibling guards are removed.
- [x] `_` loop variables renamed; repeated/non-literal values rewritten to
      `for i, x in enumerate(xs):`; inline nodes get a readable binding.
- [x] Keys and visibility follow the same guard; `plan_with_scope` exposes
      `Scope::This | Scope::All` with an all-instances verification.
- [x] Language: `in` / `not in`, `enumerate`, tuple unpacking in `for`.
- [x] Reproducible interpreter benchmark with 20 warm-up + 200 runs, median and
      p90, baseline and current measured back to back.
- [x] Gate green (fmt, clippy, workspace tests, rustdoc, boundaries, machete,
      `pctl validate`, `doc-check-refs`).

## Notas del agente

- `loop_guard.rs` implements the strategy; `plan` tries private literal,
  redundant-guard removal, loop guard, then local assignment.
- `ValueOrigins` now keeps every write in order (latest wins for lookups) so
  the planner can find the unguarded value. This made the interpreter slightly
  faster (removed the per-write `retain`).
- Verification ignores display names (presentation only); a generated binding
  renames nodes legitimately.
- Guard merges apply to a single-loop guard; different nested instances append
  a second exact guard. Instance delete (`continue`) and key removal/move
  guards wait for the phase 5 structural commands and fall back today.
- Interpreter budget: `showcase_pro.motion`, 20 warm-up + 200 runs, median:
  baseline `9f6a1c8` 1.451 ms, current 1.271 ms (-12 %); p90 1.825 -> 1.630 ms.
  Nodes 84, origins 647 -> 649.
