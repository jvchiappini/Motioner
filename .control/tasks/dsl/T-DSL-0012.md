## Contexto

Prompt 12 phase 5 (D-0036 section 3): structural UI gestures must write MDF
code instead of overrides. This closes the deferrals left by phases 3-4: the
delete of one loop instance, and key removal/moves, use the same loop guard
that values already use (`if i == 3: continue`, `if i == 3: c.key(...)`).

## Criterios de aceptacion
- [ ] Add layer (rect, circle, text, image, audio, video, path, group) inserts
      a constructor with a readable name after the selected node or at the end
      of the composition body; the new layer is selected.
- [ ] Delete removes the creation statement and the statements that only touch
      that variable; shared statements fall back.
- [ ] Duplicate copies the statements that build the node and renames the
      binding; rename edits `node.name`; reorder moves statements when creation
      order is visual order, otherwise uses z-order or falls back.
- [ ] Parent/unparent in groups is code.
- [ ] Delete one loop instance writes `if i == 3: continue` as the first
      statement of the body when that iteration creates only that node;
      otherwise fallback with a reason.
- [ ] Key add, move (retime), remove and ease changes are code; keys on loop
      instances and function calls use the same guard/assignment rules as
      values (phase 3/4).
- [ ] `visible` is code; `locked`, expanded rows and selection stay in the
      project's `editor.motion`.
- [ ] Asset placement inserts `image(...)`, `audio(...)` or `video(...)`.
- [ ] Tests cover each edit and refusal; full gate green; no commit.

## Notas del agente

- Phase 5 planner is implemented in `motioner_dsl::structural`
  (`LayerKind`, `StructuralCommand`, `plan_structural`) and key/name
  commands dispatch through `plan_with_scope`.
- The editor sink is `Editor::execute_structural`
  (`crates/motioner_ui/src/editor/mod.rs`): one exact code edit, one atomic
  program write, one undo entry; an added layer is selected.
- Deferred: the window/CLI command table does not yet expose add/delete/
  duplicate/reorder/reparent gestures as `Command` variants; the planner and
  sink are ready for that wiring.
