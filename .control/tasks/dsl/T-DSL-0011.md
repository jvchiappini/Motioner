## Contexto

D-0037 shipped cubic-bezier eases, expo/sine names, `stagger` and `wiggle`.
Missing for organic, high-end motion: physical springs and continuous noise.

## Criterios de aceptacion
- [ ] `ease=spring(stiffness, damping, mass=1)` with a closed-form,
      deterministic solution; the key's duration stays the user's
- [ ] `noise(x, y=0, seed=0)` (2D simplex/perlin, deterministic across
      platforms) and `fbm(...)` builtins in MDF
- [ ] Graph editor shows spring curves; bake writes them as `spring(...)`
- [ ] Spec section and tests that pin values bit for bit
