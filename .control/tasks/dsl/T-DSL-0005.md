## Contexto

The S-2026-10-31-009 review of core, eval and dsl produced findings that
are not blockers. Blockers and majors are handled by the hardening pass
under T-DSL-0003/T-DSL-0004; this task collects the rest so they are not
lost. Line numbers refer to commit 1f78243 and may drift.

Core: `#+1+1+1` parses as a color (`crates/motioner_core/src/color.rs:65`);
the 1M node budget lives only in the DSL, not in `Document`
(`crates/motioner_core/src/document.rs:168`); `NodeId::from_raw` is public
and can forge IDs (`crates/motioner_core/src/node.rs:20`).

Eval: `RenderPlan` text items do not carry the string or font
(`crates/motioner_eval/src/plan.rs:56`); decide together with the text
rendering work in T-RENDER-0002.

DSL: chained comparisons are rejected although the spec allows them
(`crates/motioner_dsl/src/parser.rs:378`, `spec/mdf-v0.md:239`); a tab in
a blank or comment-only line is rejected (`crates/motioner_dsl/src/lexer.rs:134`);
`for` iterates a snapshot (`crates/motioner_dsl/src/interpreter.rs:201`);
no memory budget: spec section 12 promises 256 MiB but nothing enforces
it (for example 1M `text()` nodes holding large strings); the step
budget landed in e77a524 and bounds time only;
`5 % inf` yields NaN (`crates/motioner_dsl/src/interpreter.rs:487`);
spawn-failure diagnostic uses a zero span (`crates/motioner_dsl/src/lib.rs:69`);
`#[allow(missing_docs)]` on public token enums (`crates/motioner_dsl/src/token.rs:32`);
keywords described in lowercase (`crates/motioner_dsl/src/parser.rs:683`);
`1.` and `.5` rejected (`crates/motioner_dsl/src/lexer.rs:198`); limit
helpers live in the built-ins module (`crates/motioner_dsl/src/builtins.rs:58`).

Hardening follow-ups (e77a524): `parse` and `execute` are public and run
on the caller's stack, so deep trees need the 64 MiB thread that only
`run` provides (`crates/motioner_dsl/src/lib.rs:33-37`): document it or
make them crate-private; the step-limit diagnostic lost the old "check
for runaway loops" hint; spec should state that opacity outside 0..1 is
rejected on write while evaluation still clamps eased overshoot.

All three crates lack the README required by REF-0002 section 3.

## Criterios de aceptacion
