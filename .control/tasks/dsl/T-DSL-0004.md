## Contexto

Implement the deterministic interpreter for the frozen MDF v0 subset and
the 2D scene API. Running a program builds a composition with layers,
transforms, text and shapes, plus keyframes.

The interpreter uses dynamic values, lexical scopes, deterministic
iteration order, a seeded RNG and hard limits. Scene constructors are
host functions that create document nodes. No I/O, no ambient time.

## Criterios de aceptacion
- [ ] Programs with functions, conditionals and `for` loops execute.
- [ ] `comp`, `group`, `rect`, `circle` and `text` build valid nodes.
- [ ] Position, scale, rotation, anchor, opacity and color apply.
- [ ] Linear and eased keyframes evaluate at a given frame.
- [ ] Execution is deterministic and stops at configured limits.
- [ ] Tests cover scope, errors and generated document output.
