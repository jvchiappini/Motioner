## Contexto

The hardest part of program-first authoring is letting the editor change
a compiled scene without forking the program. This task defines stable
provenance paths, the `overrides.motion` format, orphan reporting and the
bake operation that rewrites generated elements into explicit code.

Cover loops, nested functions, repeated constructors and renamed or
deleted elements. The model must be deterministic and readable.

## Criterios de aceptacion
- [x] Provenance identity is stable across runs and formatting.
- [x] The override file format and merge order are specified.
- [x] Orphan overrides are detected and reported with source spans.
- [x] Bake behavior is specified for loops and functions.
- [x] The model is documented in D-0022 and spec/mdf-v0.md §9.
