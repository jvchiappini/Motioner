## Contexto

Implement the frozen v0 subset from `spec/mdf-v0.md`: indentation,
comments, literals, identifiers, assignment, arithmetic, comparisons,
boolean operators, calls, attribute access, indexing, lists, `def`,
`return`, `if`/`elif`/`else`, `for`/`in`, `break`, `continue` and `pass`.
Exclude `while`, `use`, overrides and LaTeX.

Use a hand-written lexer and recursive-descent parser inside
`motioner_dsl`. Errors must carry line, column and category, and the AST
must be serializable for tests. No parser generator unless a limitation
is documented.

## Criterios de aceptacion
- [x] The frozen v0 subset parses with the documented grammar.
- [x] AST covers expressions, statements and function definitions.
- [x] Every parse and lexical error has a precise source span.
- [x] Unit and fuzz tests cover malformed input without panics.
- [x] The crate has no GPU or UI dependency.
