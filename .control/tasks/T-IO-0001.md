## Contexto

D-0005 fixed the folder conceptually; D-0045 turns it into the v1 contract.
Phase 1 implements it: manifest parse/validate/save, atomic writes, the asset
registry, editor and app state, project-aware input resolution and the
`new`/`migrate`/`info` CLI surface.

## Criterios de aceptacion
- [x] `motioner_io::project` loads, validates and saves the folder with typed
      errors that name the path.
- [x] Writes are atomic and a load → save round trip is byte-identical.
- [x] The image and font resolvers read through the project root; single-file
      mode keeps the working-directory behaviour.
- [x] `motioner new`, `motioner info` and `motioner migrate` work, and every
      command accepts a project folder or a `.motion`.
- [x] The gate is green with `CARGO_INCREMENTAL=0` and `-j 2`.
