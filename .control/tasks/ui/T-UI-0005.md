## Contexto

The composition was always fitted to the canvas and every window ↔
composition conversion recomputed the letterboxed rectangle. Prompt 09 phase
1 asks for zoom and pan with one mapping. Decision: D-0026.

## Criterios de aceptacion
- [x] `ViewState` holds `zoom` (`None` = fit), `pan` (composition pixels) and `fit_zoom`.
- [x] `viewport::Viewport` is the only window ↔ composition mapping; picks, bounds, gizmos, snapping, guides and the readout use it.
- [x] Commands `zoom(factor)`, `zoom_fit()`, `zoom_by(steps, x, y)`, `pan(dx, dy)` with parity, docs and state output.
- [x] Ctrl+wheel zooms around the pointer; middle/Space+drag pans; `F` and the zoom pill fit; `1` goes to 100 %.
- [x] Tests for fit, 100 %, 400 %, pan, round-trip and the fixed anchor point.
- [x] Screenshots at fit, 100 % and 400 % at 1600×900 and 1280×720 @ 125 %.

## Notas del agente

`crates/motioner_ui/src/viewport.rs`; gestures in `app/pointer.rs`,
`app/drag.rs`, `app/press.rs`; the zoom pill is a `Layout` rectangle.
Space toggles playback on release only when it did not drag (documented in
`docs/agents.md`).
