## Contexto

The first preview window (T-UI-0001, prompt 07) worked but looked amateurish:
washed-out greys (engine `Color::hex` does not linearise), labels on the bottom
edge of the bars (`draw_text` uses the em-box top as `y`), text-only buttons,
no hierarchy. Session 012 redesigned the chrome to a top-studio look (Rive,
Jitter, Figma, After Effects) inside `motioner_ui`, without engine changes.
Architecture in D-0021.

## Criterios de aceptacion
- [x] Design tokens in `theme.rs` (only colour literals; one sRGB helper,
      tested; contrast tests; 4 px grid; type scale; DPI metrics).
- [x] Painter that packs quads as `gui.wgsl` reads them (borders, shadows,
      gradients, clips, AA polygons); text with baseline, kerning, tracking,
      ellipsis.
- [x] Vector icon set (transport, loop, eye, lock, kinds, chevron, diamond,
      error, check, safe area).
- [x] Pure, tested layout with splitters and hit testing (sizes 800x500 to
      1920x1080, scales 1.0/1.25/1.5).
- [x] Top bar, layers, canvas overlays, read-only inspector, timeline with
      ruler/tracks/keyframes/playhead, status bar; empty, error and loading
      states.
- [x] Selection synced across layers, timeline, canvas (click to pick) and
      inspector; hover outline; tooltips with shortcuts; cursor changes.
- [x] Golden `hello_f120.png` unchanged; live painter test green.
- [x] Reproducible screenshots without focus (`scripts/ui_shot.ps1`).
- [ ] Editable inspector fields, visibility/lock, keyframe editing (next).
