## Contexto

Motioner was CLI-only. opencode prompt 07 added `motioner_ui` and
`motioner preview`: a Flat2D engine window that paints the evaluated plan
through `LivePainter` (same emission path as `FrameRenderer`), with transport,
scrubber, outline, status bar and polling hot reload (D-0020).

## Criterios de aceptacion
- [x] `motioner preview` opens, plays, scrubs, reloads on save and shows MDF
      diagnostics without crashing.
- [x] One emission path for headless and live; golden unchanged; live painter
      test reproduces it.
- [x] Pure, unit-tested transport (rational time, no drift), file watch,
      timeline maths, outline and input mapping.
- [x] D-0020 written; boundary script updated; `motioner_render` builds alone.
- [x] Reviewed in session 012; fixes for reload stopping playback, rate-change
      jumps, font-error exit code and loop-aware dropped frames.
