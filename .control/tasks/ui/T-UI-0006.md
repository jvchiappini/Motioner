`showcase.motion` produced 472 layers named "Circle 1..300" in a flat list.
Phase 10 fixes naming, outline and performance for large scenes.

## Design

- `node.name = "Dot grid"` in MDF (display name; identity unchanged) and
  default names from the bound variable.
- Collapsible groups, a search/filter box (`filter_layers(text)`), solo/shy
  toggles.
- Graph editor for one channel with draggable cubic-bezier handles, every edit
  a command.
- Performance: 60 fps with 1000 layers, measured; no per-frame allocations in
  timeline/outline drawing.

## Criterios de aceptacion
- [ ] Names and default names
- [ ] Search, solo/shy and collapsible groups with commands
- [ ] Graph editor commands and drawing
- [ ] Measured 60 fps with 1000 layers
