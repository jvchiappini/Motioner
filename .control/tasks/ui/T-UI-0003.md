## Contexto

`motioner preview` was a read-only viewer. This task turns it into an editor
following D-0022: every UI edit becomes an override keyed by the node's stable
identity, stored in `<name>.overrides.motion`, never touching the program. The
program changes only through `motioner bake`.

The work spans `motioner_core` (identities, visibility, content setters,
`OverrideSet`), `motioner_dsl` (provenance, `.id()`, override parsing, bake),
`motioner_eval` (hidden nodes), `motioner_ui` (session, edit model, undo,
inspector, gizmos, timeline, layers) and `motioner_app` (`bake`).

## Criterios de aceptacion

- [x] Editing a property from the inspector, the canvas or the timeline creates
      an override, is undoable, persists in `<name>.overrides.motion`, survives
      a restart and never changes the `.motion` program outside `bake`.
- [x] Selecting a layer expands its property timeline (one sub-row per property
      with its own keys, value at the playhead and stopwatch); the collapsed
      timeline shows when each layer is visible and inherited parent motion.
- [x] Provenance keys are stable for an unchanged program; `.id()` works;
      orphans are warnings and are never dropped.
- [x] `bake` is exact and idempotent and refuses unbound nodes clearly.
- [x] Visibility hides nodes and descendants in render and picking; lock blocks
      picking and editing.
- [x] The UI keeps session 012's look: tokens from `theme.rs`, icons from
      `icons.rs`, pure layouts, 4 px grid.
- [x] Golden byte-identical, all gates green, zero warnings, no new
      dependencies, no new `unsafe`.
