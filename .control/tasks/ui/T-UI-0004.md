## Contexto

The prompt 08 screenshots showed uniform visibility strips, near-invisible
eased segments, sub-rows flooded with the selection colour, stopwatches that
always looked on, mixed diamond shapes without meaning, a short timeline, a
diamond overlapping inspector labels and an Ease value that cycled on click.
Session 013 fixed them, iterating with in-app screenshots (`out/ui/p09-*`).

## Criterios de aceptacion
- [x] In-app screenshots (`preview --screenshot`, `ctl screenshot`), checked
      against PrintWindow; PrintWindow scripts deleted.
- [x] Visibility: solid bar where drawn, empty outline where not.
- [x] Eased segments: solid line whose rise follows the easing.
- [x] Selection colour only on the layer row; darker sub-row names column;
      stopwatch on (accent) / off (grey) — `animated` was always true.
- [x] One key-marker language (`widgets::key_marker`), documented in the UI
      README; selected keys on axis rows now highlight (wrong property name).
- [x] Timeline 320 px by default, draggable splitter, scrolls to the
      selection and to new selected keys.
- [x] Inspector: fixed key column, scroll thumb, wheel on every inspector
      element, ease grid with curve previews (shared ease highlighted).
- [x] Checked at 1600x900 and 1280x720 @ 125 %.
