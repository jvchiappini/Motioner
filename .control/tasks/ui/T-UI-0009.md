## Contexto

The Phase 10 review found four gaps: the graph drawn as axis-aligned boxes,
the paused blur preview taking ~1 s, `D-0044` claiming zero allocations while
the timeline formatted strings per frame, and default names colliding for
nested loops and repeated function calls.

## Criterios de aceptacion
- [x] Engine `GuiBatch::line`/`polyline` with `LINE_BIT`, shader AA, rustdoc,
      renderer docs and engine tests (clone commit `6a30e7d`).
- [x] Graph curve and handle stems use real anti-aliased segments, sampled per
      screen column; `graph_open` fits the key range and the display-name
      caption sits outside the plot.
- [x] Blur preview rewrites the sprite texture in place and reuses the
      `Evaluator`/`RenderPlan`; measured FPS table at 960x540 and 1920x1080.
- [x] Timeline value texts, labels, identity, header/ruler strings and graph
      caption are cached; the status bar shows the alloc reading.
- [x] D-0044 records the measured 9 allocations/frame and the engine reason.
- [x] Default names use the full index path and call ordinals, with a
      `HashSet` in `assign_default_names`.
- [x] Gate green; `hello_f120.png` byte-identical.
