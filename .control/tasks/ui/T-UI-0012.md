## Contexto

The Phase 0-4 review found three visible problems: OS file drops were still
behind the engine pin, the Assets header rendered the list/grid toggle as
"0 G…" at the minimum panel width, and the recent list showed a raw RFC 3339
timestamp instead of a human age.

## Criterios de aceptacion
- [x] OS drops import through `import_asset` and place on the canvas through
      `place_asset`; the window and Assets panel highlight the drag.
- [x] The list/grid toggle is a two-icon segmented control with tooltips and
      nothing in the header truncates at 180 logical px.
- [x] Recent cards show a relative age from a pure function with an injected
      `now`; the tooltip is the full local date (D-0047).
- [x] Each fix has a regression test; the gate is green.

## Notas del agente

- `app/drop.rs` and `PreviewApp::on_file_drop`.
- `Layout::asset_toolbar`/`left_tab` compact geometry, `Icon::{List, Grid,
  Clean}`, `Hit::AssetView(AssetView)`.
- `motioner_io::relative_time`/`full_local_date` (D-0047), `StartEntry.tooltip`
  and the start-screen tooltip.
