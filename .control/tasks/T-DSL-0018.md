## Contexto

D-0039 section 5. Presets are MDF functions in `std/motion.motion`; calling
`node.enter(...)` binds the node as the first argument (the interpreter
dispatches a node attribute to a user function when one exists). Defaults use
theme motion tokens and durations are in beats.

## Criterios de aceptacion
- [x] `enter`/`exit` with fade, rise, drop, slide, pop, zoom, blur, wipe, draw and spin
- [x] `emphasis` (pulse, shake, wiggle, glow, bounce), `move_to`, text `reveal`, `enter_all`/`exit_all`
- [x] a GIF per preset on the dark theme under `out/std/presets`, reviewed frame by frame
- [x] presets emit only ordinary keys and compile through bake/write-through unchanged

## Notas del agente

`count_up` needs a text-content channel the language does not have yet; it is
tracked in T-DSL-0024. `reveal` accepts `by` but the renderer only groups by
character today.
