## Contexto

The 1.0 V2 criterion: import, cut, trim and arrange video and audio on the NLE
timeline, with a proxy while scrubbing and full quality on pause/export. The
timeline already drives the evaluator with integer frames; the NLE needs a clip
model, media metadata and an ffmpeg decode path that shares the same clock.

## Criterios de aceptacion
- [ ] Clip model (source, in/out, track, speed) with undoable commands
- [ ] Import video/audio metadata and draw thumbnails on the timeline
- [ ] Cut, trim, ripple and arrange clips; proxy scrubbing
- [ ] Composite the NLE tracks with the 2D scene in one render plan
- [ ] Export MP4 with the mixed audio track
